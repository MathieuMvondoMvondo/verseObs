OBS

Votre studio. Votre diffusion.

Connectez VerseObs à OBS ou ouvrez une sortie sur un second écran.

01

Ajoutez la source dans OBS

Sources → + → Navigateur. Collez cette adresse et réglez la taille sur 1920 × 1080.

Décochez « Arrêter la source quand elle n’est pas visible » pour garder la connexion.

02

Gardez la régie dans OBS

Docks → Docks de navigateur personnalisés. Ajoutez cette adresse au dock VerseObs.

03

Vérifiez votre sortie

Ouvrez la sortie de test, puis diffusez un passage. Le voyant devient vert lorsqu’une sortie répond.

Ouvrir une sortie de test ↗Ouvrir le mode projection ↗

Télécommande sur téléphone

Passez au passage suivant, diffusez ou masquez depuis un téléphone connecté au même Wi-Fi que cet ordinateur.

Facultatif

Désactivé par défaut. Une fois activé, le Studio devient joignable sur le réseau local, protégé par un code d’appairage qui change à chaque activation.

Disponible uniquement avec le serveur local : lancez npm start sur cet ordinateur et ouvrez le Studio à l’adresse 127.0.0.1. La version en ligne (GitHub Pages) ne peut pas recevoir de télécommande.

Mode réseau local actif. Toute personne de ce Wi-Fi qui obtient ce QR code peut changer ce qui est diffusé. Ne le montrez pas à l’écran et désactivez ce mode après le culte.

  1. Connectez le téléphone au même Wi-Fi.
  2. Scannez le QR code avec l’appareil photo.
  3. Gardez la page ouverte pendant le culte.

Aucun téléphone connecté

Cette fenêtre reçoit les commandes de la télécommande.

Une autre fenêtre du Studio reçoit les commandes.

Communication locale

Le dock et la source doivent utiliser la même adresse et le même navigateur. Le serveur local relie aussi les navigateurs séparés.

Un conducteur, toute l’équipe

Exportez votre session depuis le conducteur. Votre équipier importe le fichier et retrouve les passages dans le bon ordre, avec leurs textes et leur mise en forme.
